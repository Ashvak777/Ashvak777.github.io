# Ashvak Sheik - Professional Resume Website

A professional resume website showcasing expertise in Power BI, Microsoft Fabric, and Azure Data Platform.

## 📁 Project Structure

```
Ashvak-Git-Resume/
├── index.html                 # Main website file
├── photo.jpg                  # Profile photo
├── resume/                    # Resume folder
│   └── Ashvak_PowerBI_Fabric_Developer.docx  # Latest resume
├── Projects/                  # Project showcase
│   ├── Python/               # Python projects
│   └── DataWarehouse-SQL/    # SQL and data warehouse projects
├── extract_resume.py          # Resume text extraction tool
├── resume_data.json          # Structured resume data
└── html_updates.txt          # HTML update suggestions
```

## 🚀 Quick Start

1. **View the website:**
   ```bash
   python3 -m http.server 8000
   ```
   Then visit: http://localhost:8000

2. **Update resume:**
   - Replace the file in `resume/` folder with your latest resume
   - Run the extraction tool:
   ```bash
   python3 extract_resume.py
   ```
   - Review generated files and update HTML accordingly

## 📋 Resume Management

### Adding New Resume
1. Place your latest resume in the `resume/` folder
2. Update the filename in `extract_resume.py` if needed
3. Run the extraction tool to get structured data
4. Update the HTML with new information

### Resume Extraction Tool
The `extract_resume.py` script:
- Extracts text from Word documents
- Structures data into organized sections
- Generates HTML update suggestions
- Saves structured data for easy updates
